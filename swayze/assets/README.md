# Local asset folder

This folder contains local copies of static assets downloaded from the supplied template snapshot.

Use local client files here for:

- `client-logo.svg` or `client-logo.png`
- `client-hero.webp` or `client-hero.jpg`
- `client-og-image.png`
- client favicon files
- client video files, if the final demo needs to work offline

After adding client assets, update the paths in `config.js` and confirm the generated HTML references the correct files. Do not put API keys, tracking secrets, or form credentials in this folder or in any browser-delivered file.
