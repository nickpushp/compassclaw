# Keeton Electric Demo

This demo uses the uploaded electrical rebrand as its visual master. The client build keeps the same component system and visual language while swapping the business identity, contact information, service area and imagery.

Business data used for this demo:
- Keeton Electric
- 1309 E 41st St, Tacoma, WA 98404
- 253-448-3210
- Washington contractor license: KEETOE872C6

The demo intentionally avoids inventing customer reviews and replaces the original template's placeholder testimonials with service highlights.

## Local preview

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
