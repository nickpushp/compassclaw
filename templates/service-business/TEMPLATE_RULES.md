# Service Business Master Template

This folder is the exact React/Vite source that was uploaded as the electrical rebrand template.

## Locked design rule

Do not redesign, restructure, refactor, modernize, or simplify this UI when creating client demos.

Preserve the DOM structure, Tailwind styling, typography, spacing, animations, responsive behavior, components, interactions, modals, calculators, and overall visual design.

For a client demo, only replace:
- Business name and contact information
- Service-area copy
- Verified business/service claims
- Niche-specific imagery
- Verified reviews/testimonials when supplied

If a requested client change requires changing the visual system or component structure, stop and ask for approval first.
