# Compass Claw White-Label Service Business Template

## LOCKED DESIGN RULE
This template is the master website design. Do NOT redesign, restructure, refactor, modernize, or rewrite the HTML/CSS/layout when creating a client site.

Preserve exactly:
- DOM/page structure
- CSS and visual styling
- fonts
- animations
- navigation
- buttons and CTAs
- sections and spacing
- responsive/mobile behavior
- existing functionality
- reusable F1/F2/F3 assets

## Allowed client changes
Only change:
1. Business/customer-facing copy in `CONFIG`.
2. `CONFIG.img.hero` — niche-specific hero image.
3. `CONFIG.img.team` — niche-specific technician/driver image.
4. Business details such as name, phone, city/service area, services, reviews, trust stats, FAQs, and CTAs.

F1/F2/F3 are reusable template assets and should normally NOT be replaced.

## Workflow
1. Copy the template.
2. Change CONFIG values only.
3. Replace hero + technician/driver images.
4. Do not touch the design unless the client explicitly requests a structural/design change.

If a request cannot be completed by changing CONFIG or the two niche-specific images, stop and ask before changing the template design.
